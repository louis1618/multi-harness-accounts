# 검증 기록

## 1.0.2 · Paseo 0.11.1 앱 호환

2026-10-08

- 지원 범위 `>=0.10.0 <0.12.0`, 개발용 plugin/client/protocol SDK 0.11.1로 갱신. 타입 검사 통과.
- 실제 0.10.3 daemon에서 서버·클라이언트 번들 컴파일 및 reload 후 running 확인. 앱 catalog의 호환 범위에 0.11.1 포함.
- 상태 파일 보존, 메인 daemon 재시작 없음. 정리·프로세스 종료·Docker 변경·관리자 도우미 재설치를 실행하지 않았다.

## 최초 구현

2026-10-02, Ubuntu 24.04.5 / Docker Engine 29.8.1 / Paseo 0.10.0 호스트에서 확인했습니다.

## 완료

- `npm run typecheck`: 통과.
- `npm test`: Node 기본 테스트 16개 통과.
- `npm run test:helper`: 관리자 도우미 테스트 3개 통과. 실제 APT/journal 실행은 대역 처리했습니다.
- Paseo 실제 compiler: client/server 번들 컴파일 통과. 개발 의존성이 없는 복사본도 컴파일했습니다.
- 실제 Paseo RPC: 디스크·CPU·메모리·프로그램·Docker 목록, 분석 완료/일부 미조회 상태와 제한된 로그 조회 확인.
- 컨테이너 33개(실행 32개), 이미지 28개, 볼륨 30개, 네트워크 18개, 스택 8개 조회.
- 확인하지 못한 Compose 참조는 이미지·네트워크 정리를 보호했습니다. `/root`, `/lost+found`, Docker 저장소 등 접근 불가/제외 영역은 미조회로 표시했습니다.
- 보호 이미지 미리보기 제외, `confirmed: false` 실행과 볼륨 삭제 요청의 RPC 거부 확인. 실제 호스트 작업 이력은 0건입니다.
- 관리자 도우미는 root:root 0755, Polkit 정책은 root:root 0644이며 검토한 소스와 동일합니다. 정책은 매번 `auth_admin`을 요구합니다.
- 메인 데몬의 PID 2762와 시작 시각은 유지했습니다. 새 플러그인만 설치/갱신했습니다.
- 검증용 별도 데몬 종료 후 임시 데이터와 자동 다운로드된 모델 파일을 제거했습니다.

## 보호 시나리오

실행·중지 컨테이너 참조, 공유 이미지 레이어, 로컬 이미지 보호, Compose 누락/조회 실패, 선택 대상 변경, 경로 링크, 열린 썸네일, PID 재사용, 핵심/코딩 에이전트 프로세스 보호, 작업 직렬화·취소·부분 실패, 미리보기 만료, 재시작 후 미완료 작업의 재실행 방지, 관리자 승인 취소, 인증 정보 숨김과 제한된 로그 크기를 검사했습니다.

삭제 테스트는 전용 임시 파일과 가짜 Docker 실행기, 종료 테스트는 가짜 신호 전달기로 수행했습니다. 실사용 서비스·컨테이너·볼륨·개인 파일을 삭제하거나 중지하지 않았습니다. 리셋권 기능은 사용하지 않았습니다.

## 아직 확인하지 못한 항목

현재 컴퓨터 제어 도구에 연결된 브라우저가 없어 실제 데스크톱·모바일 화면을 조작하거나 캡처하지 못했습니다. UI는 Paseo의 React Native/Modal/설정 컴포넌트, 테마 색상, compact 레이아웃과 44px 버튼을 사용하며 타입·번들 검사는 통과했습니다. 실제 iPad/모바일 앱 시각·터치 검증은 남아 있습니다.
