# Home Finder — Paseo 파일 탐색기

Paseo 사이드바의 **파일**에서 데몬 사용자의 홈 폴더를 탐색합니다. Finder의 도구 막대·사이드바·선택·보기 방식을 따르는 한국어 인터페이스입니다.

## 설치 및 갱신

Paseo 0.10.x 또는 0.11.x와 Node.js 22 이상이 필요합니다. 1.3.1부터 개발 SDK·클라이언트·프로토콜을 0.11.1로 맞췄으며 기존 사이드바 API를 유지합니다. Linux 휴지통에는 `gio`, 문서·압축파일 내용 읽기에는 Python 3, PDF 페이지 이미지에는 `pdftoppm`을 사용합니다. 해당 도구가 없으면 다운로드하여 전용 앱에서 열 수 있습니다.

```sh
paseo plugin install 'github:louis1618/paseo-plugins:plugins/home-finder'
paseo plugin ls
```

로컬 폴더에서 설치하려면 저장소를 clone한 뒤 실행합니다.

```sh
git clone https://github.com/louis1618/paseo-plugins.git
cd paseo-plugins
paseo plugin install "$(pwd)/plugins/home-finder"
```

소스를 수정한 뒤에는 `paseo plugin reload home-finder`로 다시 불러옵니다.

## 파일 관리

- 아이콘·목록·열·갤러리 보기, 이름·날짜·크기·종류 정렬, 오름·내림차순.
- 뒤로·앞으로·상위 폴더·경로 탐색, 현재 폴더 이름 검색. 숨김 파일과 `.dev`도 기본 표시합니다.
- 이름 변경, 새 폴더, 복사·잘라내기·붙여넣기, 파일·폴더 즐겨찾기.
- 단일·범위·다중·전체 선택. 터치에서는 작업 메뉴의 다중 선택 또는 길게 누르기를 사용합니다.
- 삭제 확인 후 Linux 휴지통 이동, 원래 위치 복원. 기존 파일을 덮어쓰거나 영구 삭제하지 않습니다.
- 작업 메뉴에 새 폴더·전체 선택·즐겨찾기·보기 옵션·새로고침을 모았습니다. 데스크톱은 한 줄 도구 막대, 좁은 화면은 선택 시 다운로드·미리보기 도구를 표시합니다. 검색은 검색 버튼으로 엽니다.

## 다운로드: 브라우저 URL만 사용

파일을 선택하고 **다운로드**를 누르면 버튼을 누른 기기의 브라우저에서 받습니다. iPhone/iPad는 Safari 등 기본 브라우저의 다운로드·파일 저장 기능을 사용합니다. Paseo 앱 내부 저장이나 공유 기능은 사용하지 않습니다.

단일 파일의 URL은 선택할 때 미리 준비하여 브라우저의 사용자 클릭 흐름을 유지합니다. 준비되지 않은 링크나 여러 파일은 간단한 다운로드 목록으로 표시하며 파일별 다운로드·링크 복사를 제공합니다. 한 번에 최대 16개 파일, 폴더 다운로드는 지원하지 않습니다.

- 파일마다 256비트 임시 권한 토큰을 발급합니다. 링크를 가진 사람은 해당 파일을 읽을 수 있으며, 30분 후 또는 플러그인 재시작 시 만료됩니다. URL은 로그에 남기지 않습니다.
- GET/HEAD와 단일 Range 요청을 지원합니다. 다운로드는 attachment, 미리보기는 inline이며 영상 탐색·큰 파일 전송을 지원합니다. 파일 목록·일반 경로·쓰기 API는 노출하지 않습니다.
- 첫 링크 요청 시 하나의 VPN/사설 주소에만 서버를 엽니다. Tailscale → 내부망 → localhost 순으로 선택하며 기본 포트는 17767입니다. 포트 충돌 시 빈 포트를 사용합니다. 링크는 최대 64개입니다.
- **클라이언트 브라우저에서 해당 파일 서버에 직접 접근할 수 있는 VPN·네트워크 연결이 필요합니다.** Paseo relay는 파일 URL을 중계하지 않습니다. localhost 주소는 원격 기기에서 사용할 수 없습니다.
- 필요하면 작업 메뉴 → 보기 옵션 → 다운로드 연결 설정에 이미 구성한 HTTPS 역방향 프록시 주소를 입력하세요. 프록시는 파일 서버로 연결되고 경로 접두사를 제거해야 합니다. 플러그인은 DNS·인증서·VPN·방화벽을 변경하지 않습니다.

## 미리보기

| 종류 | 방식 |
|---|---|
| 영상·음원 | MP4/MOV/WebM, MP3/M4A/AAC/WAV/FLAC 등 기기가 지원하는 형식을 재생·탐색합니다. 지원 코덱은 기기에 따라 다릅니다. |
| 이미지 | PNG/JPEG/GIF/WebP/AVIF/BMP/SVG/TIFF/HEIC 등 기기가 지원하는 이미지. 5MB 이하 일반 이미지는 인증된 RPC에서도 표시합니다. |
| PDF | 50MB 이하 파일의 앞부분 최대 3페이지를 이미지로 표시하고 전체는 브라우저에서 엽니다. |
| Office·EPUB | DOCX/XLSX/PPTX/ODT/ODS/ODP/EPUB의 텍스트·셀 내용을 표시합니다. 원본 서식 렌더링·수식·매크로 실행은 하지 않습니다. |
| 압축파일 | ZIP/TAR/TGZ 등의 앞부분 최대 300개 항목을 추출 없이 표시합니다. RAR/7z·구형 Office는 전용 앱에서 엽니다. |
| 텍스트·코드 | UTF-8/UTF-16, CSV/JSON/HTML/로그 등 앞부분 128KB. HTML을 실행하지 않습니다. |
| 기타 바이너리 | 앞부분 최대 512바이트와 파일 정보를 표시합니다. |

앱의 미디어 미리보기는 Paseo에 포함된 WebView를 사용합니다. 연결·코덱 오류 또는 모듈 누락 시 브라우저 미리보기 안내를 제공합니다.

## 저장 및 경계

즐겨찾기·파일 URL 기본 주소는 `$PASEO_HOME/home-finder/state.json`에 원자적으로 저장합니다. 디렉터리는 `0700`, 파일은 `0600`입니다. 기존 계정 플러그인과 분리됩니다.

홈 밖 경로·외부를 가리키는 심볼릭 링크의 읽기·다운로드를 차단합니다. 링크 자체의 이름 변경·휴지통 이동은 가능합니다. 홈 폴더 자체·장치·FIFO는 변경·다운로드하지 않습니다. 검색은 현재 폴더 이름 검색이고, 50,000개를 넘는 단일 폴더는 열지 않습니다. 아이콘·목록은 가상화합니다.

## 개발 및 검증

React·React Native·SDK·TanStack Query·Zod는 Paseo 런타임이 제공합니다. 플러그인의 별도 모바일 저장 의존성은 없습니다.

```sh
npm ci --ignore-scripts --legacy-peer-deps
npm run typecheck
npm run check
npm run check:bundle -- /실제/경로/compiled-client.js
```

자체 생성한 임시 파일로 홈 경계, 이름 변경·복사·즐겨찾기·휴지통 복원, URL 전송·HEAD·구간 읽기·만료·파일 변경, 문서·압축 읽기를 검사합니다. 번들 검사는 앱 내부 저장 코드가 없고 미디어·키보드 연결이 유지되는지 확인합니다. 실제 iPad에서 저장 완료를 검증한 것은 아닙니다. 갱신 후 모바일 앱의 파일 화면을 닫고 다시 열어주세요.
